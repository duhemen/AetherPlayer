## 🚀 **Overview**

**AetherPlayer** is a **next-generation, AI-powered virtual studio and karaoke live streaming platform** that revolutionizes content creation. By combining **real-time facial tracking**, **augmented reality effects**, **multi-format media playback**, and **professional live streaming** capabilities, it transforms your webcam into a fully-featured broadcast studio.

> 💡 **Vision**: Democratizing professional streaming by making studio-quality effects accessible to everyone with just a webcam.

---

## ✨ **Key Features**

| Feature | Description |
|---------|-------------|
| 🎤 **Karaoke Mode** | Video/audio playback with synchronized lyrics (.lrc support) |
| 🤖 **AI Face Tracking** | Real-time facial landmark detection using MediaPipe |
| 🎭 **AR Effects** | Dynamic facial distortions, blush, and expression-based reactions |
| 📡 **Live Streaming** | RTMP streaming to YouTube, Facebook, Twitch, and more |
| 🎵 **Multi-Format Support** | MP3, WAV, OGG, FLAC, MP4, AVI, MKV, MOV, WEBM |
| 🎬 **Video Overlay** | Picture-in-picture playback with adjustable opacity |
| ⚙️ **Modern UI** | Dark mode interface with CustomTkinter |
| ⌨️ **Keyboard Shortcuts** | Space, S, L for quick control |
| 💾 **Settings Management** | Persistent URL and Stream Key storage |

## 🎯 **AR Effects Guide**

### How It Works

The AI analyzes your facial expressions in real-time and applies dynamic AR effects based on:

1. **Smile Ratio** - Width/Height ratio of your mouth
2. **Eyebrow Height** - Vertical distance between eyebrows
3. **Nose Position** - Vertical position of your nose
4. **Movement Detection** - How long you stay still

### Expression-Based Effects

| Expression | Detection Criteria | AR Effect |
|------------|-------------------|-----------|
| 😍 **Happy** | Smile Ratio > 3.2 | 🌸 Blush on cheeks + warm glow |
| 🤨 **Suspicious** | Eyebrows > 7px + Smile < 3.0 | 🔮 Warp effect + "???" floating text |
| 😭 **Sad** | Smile Ratio < 2.2 | 💧 Tear drops + downward warp |
| 👑 **Proud** | Nose < 45% height + Smile < 2.5 | ✨ Sultan warp effect |
| 🧠 **Blank** | No movement > 3 seconds | 💫 "Loading... 404" + expanding warp |

### Lyrics File Format

Create a `.lrc` file with the same name as your video/audio:

```lrc
[00:00.00] Judul Lagu - Artis
[00:05.00] 
[00:08.00] Di ujung jalan ini
[00:12.00] Ku teringat senyummu
[00:16.00] Yang dulu pernah ada
[00:20.00] Menemani langkahku
```

## 🌐 **Streaming Setup**

### YouTube Live

1. Go to **YouTube Studio** → **Create** → **Go Live**
2. Copy your **Stream Key**
3. In AetherPlayer, click **Settings** ⚙️
4. Set URL to: `rtmp://a.rtmp.youtube.com/live2`
5. Paste your Stream Key
6. Click **GO LIVE** 📡

### Facebook Live

1. Go to **Facebook Creator Studio** → **Live**
2. Copy your **Stream Key**
3. In AetherPlayer, click **Settings** ⚙️
4. Set URL to: `rtmp://live-api.facebook.com:443/rtmp/`
5. Paste your Stream Key
6. Click **GO LIVE** 📡

### Custom RTMP Server

```python
# config.py
DEFAULT_RTMP_URL = "rtmp://your-server.com/live"
DEFAULT_STREAM_KEY = "your-stream-key"
```

## 🚨 **Troubleshooting**

### Common Issues & Solutions

| Issue | Solution |
|-------|----------|
| ❌ **FFmpeg not found** | Download from [ffmpeg.org](https://ffmpeg.org/download.html) and place in project folder or add to PATH |
| ❌ **Camera not working** | Check camera permissions, try different camera index (change `cv2.VideoCapture(0)` to `1`) |
| ❌ **No audio from video** | Ensure FFmpeg is installed for audio extraction, or use MP3 files directly |
| ❌ **Black screen on video** | Check video codec support (H.264 recommended), convert video using FFmpeg |
| ❌ **Streaming fails** | Verify RTMP URL and Stream Key are correct, check internet connection |
| ❌ **MediaPipe import error** | Install `mediapipe==0.10.7` or use `cvzone` fallback |
| ❌ **High CPU usage** | Reduce video resolution, lower FPS, close background applications |
